# Nikita Khandare — Portfolio Website

A personal portfolio site built with plain HTML, CSS and JavaScript (no frameworks).

## What's inside

- **Hero / intro** — name and one-line pitch
- **About** — background, education, research paper
- **Skills** — languages, frameworks, tools
- **Work** — 4 project showcases, each with tech stack and a GitHub link
- **Contact** — email + LinkedIn + GitHub

## Tech used

- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 — custom properties, Flexbox, Grid, media queries (responsive at 375px / 768px / 1280px+)
- Vanilla JavaScript — mobile nav toggle, light/dark theme toggle (persisted via `localStorage`), and a project filter by category

## Run it locally

No build step needed.

1. Clone the repo:
   ```
   git clone https://github.com/NikitagajananKhandare28/portfolio-website.git
   cd portfolio-website
   ```
2. Open `index.html` directly in a browser, **or** for live-reload while editing, use the VS Code "Live Server" extension and click "Go Live".
